# Code of conduct

Be kind, be specific, assume good intent. Criticise code and ideas, not people. Harassment, discrimination and
personal attacks are not welcome here in any form.

If something goes wrong, contact the maintainer through a private security advisory on this repository. Reports
are handled in confidence, and maintainers may remove comments, commits and contributors that break these rules.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
